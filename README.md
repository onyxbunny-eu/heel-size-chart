# Women's Heel Size Chart & Converter (EU, US, UK, cm)

Women's heel size chart and converter for EU, US, UK and foot length in centimetres and inches, made by [Onyx Bunny](https://onyxbunny.com/), an 18+ shop that sells made-to-order designer heels.

This is a no-build static site for GitHub Pages. It includes:

- an interactive women's shoe size converter;
- a full HTML conversion table;
- a heel height guide in centimetres and inches;
- six sizing FAQs with FAQPage structured data; and
- Organization structured data for Onyx Bunny.

Conversions are approximate because sizing varies by brand and style. Check the footwear maker's own chart before buying.

## Publish on GitHub Pages

1. Create a public repository named `heel-size-chart`.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.
5. Add the published URL to the repository's **About** section.

No build step, package installation, analytics, tracking or external JavaScript is used.
